## How to add one (2 minutes)

1. Finish the certification on freeCodeCamp and claim it from your [settings page](https://www.freecodecamp.org/settings).
2. Open the certificate page: `https://www.freecodecamp.org/certification/kirigamii/<slug>`
3. Download the PDF (button on that page) and rename it to match the slug, e.g. `responsive-web-design.pdf`.
4. Drop it in this folder.
5. Add a row to the table above:

```markdown
| [Responsive Web Design](https://www.freecodecamp.org/certification/kirigamii/responsive-web-design) | 2026 | [verify](https://www.freecodecamp.org/certification/kirigamii/responsive-web-design) | [PDF](./responsive-web-design.pdf) |
```

6. Add the badge in the main `README.md` (there is a ready `TEMPLATE` comment in the `CERTIFICATIONS` section).
